# Казино-бот: орел или решка

Telegram-бот на Python и aiogram 3 для игры на виртуальные фишки. Реальные
деньги, платежи и вывод средств не поддерживаются.

## Возможности

- Баланс игрока хранится в SQLite.
- Новый игрок получает 1 000 виртуальных фишек.
- `/balance` показывает баланс.
- `/flip <ставка> <орел|решка>` запускает игру. Допускаются также варианты
  `орёл`, `heads` и `tails`.
- При победе к балансу прибавляется размер ставки; при проигрыше он списывается.
- Нельзя поставить ноль, отрицательное число или больше текущего баланса.
- Исключения базы данных записываются в лог; временная ошибка не раскрывает
  пользователю технические подробности.

## Запуск

1. Установите Python 3.10+.
2. Создайте и активируйте виртуальное окружение, затем установите зависимости:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Создайте бота через [@BotFather](https://t.me/BotFather). Скопируйте
   `.env.example` в `.env` и вставьте выданный токен в `BOT_TOKEN`.
4. Запустите бота:

   ```powershell
   python bot.py
   ```

База данных `casino.db` создаётся автоматически при первом запуске. Команда
`/start` показывает правила, а `/help` — краткую справку.
